AutoProof tutorial

This tutorial provides a systematic description of how to use AutoProof. For a shorter introduction refer to the AutoProof quick start guide.

The tutorial is based on the March 2015 PDF version of the “AutoProof Tutorial” by the Chair of Software Engineering of ETH Zurich.

This guide is work in progress. Sections are being moved from the PDF to this site and the text is being adapted for the changes in AutoProof since 2015.
